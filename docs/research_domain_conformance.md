## Release evidence

- The [normal release workflow](../.github/workflows/test.yml) runs `python tools/run_validation.py` on Linux with Python 3.11, 3.12, and 3.13. Record the run link and the executed, passed, and skipped test counts for each version. Record the six native Windows domain-index ownership cases on each of Python 3.12 and 3.13 with their exit status.
- Run `python -m build --outdir "$scratch/dist"` from the checkout. From outside the checkout run `python "$checkout/tools/validate_domain_wheel.py" --wheel "$wheel" --report "$scratch/wheel.json"` with the absolute wheel path. Record the wheel SHA-256, schema count, and installed conformance count. The installed lifecycle uses an authenticated SQLite read with two identical quotes. The chemistry query selects both evidence records, and the biology query selects only its reviewed evidence record. Each context is validated against current access and source status.
- Check the externally supplied legacy file with `git hash-object "$legacy"`, then run `python tools/check_legacy.py --core "$legacy" --output "$scratch/legacy.json"`. Record the exact blob and both the overall and nested classification check counts from that report. A skip in the normal release workflow leaves this gate unexecuted.
